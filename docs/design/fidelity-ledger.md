# 視覺 Fidelity Ledger

## 核准基準

- `approved-gameplay.png`：遊戲棋盤、規則卡、HUD 與底部操作列。
- `approved-level-select.png`：關卡包 accordion、進度、10 關分頁與鎖定狀態。
- `approved-completion.png`：完成 dialog、星級、時間與下一關操作。

## 實作對照

| 項目 | 狀態 | 說明 |
| --- | --- | --- |
| 溫暖奶油色背景、珊瑚色標題、圓角卡片 | 符合 | 延續三張核准概念的活潑貓咪語言。 |
| 彩色連通區域與加粗區域邊界 | 符合 | 色彩不是唯一提示，區域邊界同步提供結構辨識。 |
| 10 關一頁 accordion 選關 | 符合 | 一次只展開一包，頁碼由 pack 資料推導。 |
| 完成星級與下一關 dialog | 符合 | 顯示星級、時間、步數、提示與主要下一步。 |
| 320px 的 12×12 棋盤 | 符合 | 棋盤保持正方形且完整縮放，頁面不產生水平捲動。 |
| 貓咪與功能圖示 | 有意調整 | 使用原創 inline SVG 與 CSS 向量造型，避免任何 runtime 圖片請求並確保小格清晰。 |
| 行動版導覽 | 有意調整 | 小螢幕隱藏品牌字樣，保留返回、設定、關卡資訊與完整操作區。 |
| 廣告區 | 不採用 | 核准參考圖中的廣告不屬於單機離線遊戲需求。 |

## QA 原則

- 核准概念圖只作視覺規格，不作執行時素材。
- 每次重大 UI 修改後，比對最新桌面／320px 截圖與本表。
- 無障礙、棋盤可讀性與離線可靠性優先於像素級裝飾一致。
