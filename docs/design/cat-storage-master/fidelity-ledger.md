## 有意保留的差異

- 參考圖採高擬真 3D 插畫；實作依「不下載第三方素材、只用原創本機資源」限制，採較清楚、可縮放的原創 inline SVG 與 CSS 插畫。
- 參考畫面是已進行中的第 38 關；比較截圖是未放置的第 2 關，用來驗證共同版型、資訊層級、材質、色彩與控制密度，不宣稱內容狀態相同。
- 參考圖底部有額外室內裝飾；實作減少不影響玩法的裝飾，優先保留 320px 操作面積、可讀性與無水平捲動。
