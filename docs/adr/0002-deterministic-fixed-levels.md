# ADR-0002：開發期生成、執行期固定的唯一解關卡

## Status

Accepted

## Decision

關卡包設定是唯一的人工作業入口。產生器使用 seeded PRNG 建立候選，只有通過唯一解、連通性與正規化去重的關卡才能寫入固定 levels 資料。

「唯一解」以各遊戲的實質解答等價關係判定。若遊戲規則本身允許多條等價操作順序，且使用者在該遊戲規格中明確核准不要求唯一順序（例如《貓咪三層配對》），則發布閘門改為要求至少一條獨立 Solver 認證的完整解、所有資源上限均合規，以及版面 D4／內容換名不重複；不得把 `knownSolution` 當成 Solver 輸入。

## Consequences

- 執行期不生成或隨機化關卡。
- 重新執行產生器必須輸出相同內容。
- 新增 4×4～12×12 關卡包只需修改設定並重新生成、驗證。
