# 貓咪方格 100 關可擴充版

**Status:** ready-for-agent

## Problem Statement

使用者需要一款不依賴伺服器、網路或安裝流程的貓咪主題區域邏輯遊戲，並希望首版已有大量固定唯一解關卡，未來仍可透過設定與產生器擴充。

## Solution

提供可直接雙擊開啟的純前端遊戲。遊戲含四個獨立關卡包、100 個固定關卡、完整推理操作、衝突提示、提示、復原、進度與星級，並以資料驅動關卡包及 deterministic generator 支援擴充。

## User Stories

1. 作為玩家，我想直接雙擊遊戲檔案，以便完全離線遊玩。
2. 作為玩家，我想在四種棋盤尺寸間自由選擇，以便依偏好挑戰。
3. 作為玩家，我想逐關解鎖並看到星級，以便掌握進度。
4. 作為玩家，我想用空白、X、貓咪循環記錄推理，以便操作快速一致。
5. 作為玩家，我想看到列、欄、區域與接觸衝突，以便自行修正。
6. 作為玩家，我想關閉自動檢查，以便不被即時紅框干擾。
7. 作為玩家，我想使用只高亮、不代放的提示，以便保留解題感。
8. 作為玩家，我想復原、重玩與返回選關，以便控制目前回合。
9. 作為鍵盤使用者，我想用 Tab、Enter、Space 操作並聽到狀態訊息。
10. 作為手機使用者，我想在 320px 寬度完整看到 12×12 棋盤。
11. 作為維護者，我想只改關卡包設定就能增加關卡，以便安全擴充內容。
12. 作為維護者，我想由求解器重新驗證每關，以免固定資料含錯誤或多解。

## Implementation Decisions

- 四個關卡包分別為 15、20、30、35 關，共 100 關。
- packs、core、levels 同時支援瀏覽器全域與 CommonJS。
- 棋盤格狀態為 EMPTY、X、CAT；X 不參與規則。
- 選關使用一次展開一包的 accordion，每頁最多 10 關。
- localStorage 使用 `cat-grid-game:v1`，以 pack ID 與 level ID 儲存。
- 計時從載入關卡開始，完成時停止。
- 每個格子操作增加步數；復原不改變累積步數。
- inline SVG 是經核准的遊戲向量美術方案。

## Testing Decisions

- 純規則只測 public API，不測內部 helper。
- 每關由求解器重新計數到 2，不信任保存 solution。
- 真實瀏覽器 seam 使用 `file://` 驗證核心流程、console、localStorage、響應式與無障礙。
- 產生器必須通過第二次執行零差異的重現性檢查。

## Out of Scope
