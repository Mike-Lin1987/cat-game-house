# 10 — 備用格與空牌堆移牌

## Tracer bullet

以 `CatWordCore` 公開動作完成「露出牌 → 備用格 → 空牌堆 → 分類槽」，
再讓 Solver、session、提示、Pointer／點選／鍵盤 UI 共用同一規則。

## 驗收

- [x] 初始盤面固定建立 2 個空備用格。
- [x] 任一露出牌可移入空備用格，備用牌可移出，且每次實際移動算一步。
- [x] 完全空白的牌堆可接收露出牌；非空牌堆及原地移動均拒絕。
- [x] 分類牌與提示牌可直接從備用格放入合法分類槽。
- [x] 完成判斷、撤回、提示、卡關及 session 都包含備用格狀態。
- [x] Solver 防止備用格／空欄循環，100 關仍可解且不超過 25,000 節點。
- [x] Pointer、點選與鍵盤皆可操作備用格與空牌堆。
- [x] 320×568 無水平捲動，規則文案及無障礙名稱完整。
- [x] 完整 `npm run verify` 與真實瀏覽器 QA 通過。
