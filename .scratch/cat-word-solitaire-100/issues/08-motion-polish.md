# Ticket 08：發牌與拖曳動效

- Status: done
- Blocked by: 04-runtime-ui

## 範圍

在不修改 Core 規則與 54 張固定關卡資料的前提下，加入接龍式發牌動畫、
Pointer 浮牌拖曳、合法／無效分類槽提示、吸附落位與錯誤回彈。

## 驗收

- 每批最多五張牌從右上牌庫依左至右飛入對應牌堆。
- 發牌動畫期間不接受第二次發牌，完成後恢復操作。
- 拖曳浮牌與指標同步，原牌保留占位且版面不跳動。
- 分類牌只提示空槽；提示牌只提示同分類的啟用槽。
- 合法放置吸附、無效放置回彈；Pointer cancel 與失焦不留下 ghost。
- 動畫設定與 reduced motion 均可停用非必要過場。
- 桌面與 320px 手機版無水平溢位，Pointer、點選與鍵盤均可操作。
